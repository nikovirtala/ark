# Configure ark's own agents with MCP servers, skills, hooks and permissions

## Goal
Give every person and agent working on ark the ark tools by default: adr and issues MCP servers, their skills, harness hooks and permission rules for Claude Code and Kiro, and git hooks installed by pnpm install. Today none of it is configured, so ark's agents work on ark without ark.

## Notes
Follow the agent setup design (docs/03-setup-v1.md), which lists every file and why, and the proposed decision to run ark's own tooling from the previous release (adr:jgdhvxtq): pin exact published versions, never the workspace build.

This is configured by hand, once. Making init write the same setup for every repository is a separate issue; when it lands, the files here are regenerated by it and must come out the same.

ARK_ON_BEHALF_OF names a person, so it is never committed: the configs read it from each developer's environment. Check the current Claude Code and Kiro documentation for the exact config, hook and permission formats before writing them.

## Done when
- .mcp.json and .kiro/settings/mcp.json start adr and issues at exact published versions, with ARK_AGENT set per harness and ARK_ON_BEHALF_OF taken from the environment.
- The adr and issues skills are installed for both harnesses, and AGENTS.md points at them.
- A session-start hook shows ready issues and records changed since the last session; a hook before each file edit shows the decisions and open issues for that file, in both harnesses.
- Direct edits to docs/*/events/**, docs/*/index.md and docs/adr/decisions/** are denied to agents in both harnesses.
- pnpm install in a fresh clone installs the git hooks.
- adr:jgdhvxtq is accepted in the same pull request.
